# IPFranked Social Graphics Style Guide

Visual spec for the Instagram graphics generated by `scripts/social/`. The goal
is that every post — today's and a year from now — reads as the same brand.
Everything here is enforced in code (`scripts/social/shared.py` and friends),
not just described, so running the generators is how you "follow" this guide.

## Canvas

- **1080×1350px** (Instagram portrait, 4:5) for every slide in a carousel.
- Background is always solid `--bg` (see palette) — no gradients, no photos.

## Palette

Matches `frontend/index.html`'s `:root` variables exactly, so the graphics and
the live site never drift apart.

| Role | Hex | Usage |
|---|---|---|
| `--bg` | `#0f1115` | Canvas background |
| `--panel` | `#171a21` | Even-indexed table rows |
| `--panel-2` | `#1e2229` | Odd-indexed table rows (alternating stripe) |
| `--border` | `#2a2f3a` | Rule lines, row dividers |
| `--text` | `#e8eaed` | Primary text (names, "ranked" in wordmark) |
| `--text-dim` | `#9aa1ac` | Secondary text (labels, bodyweight, date, footer) |
| `--accent` | `#4f8cff` | "IPF" in wordmark, headline ranking metric, CTA sub-line |
| `--gold` | `#d4af37` | Rank #1 badge |
| `--silver` | `#b0b8c1` | Rank #2 badge |
| `--bronze` | `#c17a4a` | Rank #3 badge |
| `#1a1a1a` | — | Text color *inside* a gold/silver/bronze badge |

## Typography

- **Segoe UI** family throughout — Bold (`segoeuib.ttf`), Regular
  (`segoeui.ttf`), Semibold (`seguisb.ttf`) — matching the site's own
  `-apple-system, "Segoe UI", Roboto, Helvetica, Arial, sans-serif` stack.
- **CJK fallback**: Segoe UI has no CJK/Hangul/Kana glyphs. Any character in
  those ranges is rendered with Microsoft YaHei (`msyh.ttc`) instead, per
  character, so non-Latin names never render as tofu boxes. Always draw
  lifter names through `draw_mixed_text()` — never raw `draw.text()` — so this
  fallback applies automatically.
- Numeric columns use **tabular figures implicitly** via fixed-width right
  alignment — always right-align numbers to a column's right edge.

## The IPFranked wordmark

"IPF" in `--accent`, "ranked" in `--text`, both bold, same font size, no space
between them. Two variants, both via `shared.py`:

- `draw_wordmark()` — large (80px), horizontally centered. Used on title and
  outro slides. Always paired with a short horizontal `--accent` rule
  (4px thick, 90px wide, centered) 70px below the wordmark's center line.
- `draw_inline_wordmark()` — smaller (50px), left-aligned. Used atop
  leaderboard slides, paired with a dim uppercase subtitle line below it
  (e.g. "MEN'S 83KG — TOP 15") and a full-width `--border` rule beneath both.

## Slide types

### 1. Title slide (`make_title_slide.py` → `build_title_slide`)

Opens every carousel. Centered, generous negative space top and bottom.

- Wordmark at 34% of canvas height.
- Category headline (e.g. "MEN'S", "WOMEN'S", "POUND-FOR-POUND") — bold,
  64px, `--text`, uppercase, centered at 52% height.
- Subtitle (e.g. "TOP 15 LEADERBOARDS", "TOP 15 BY DOTS") — semibold, 40px,
  `--accent`, centered just below the headline.
- "Data as of {date}" — regular, 26px, `--text-dim`, centered at 64% height.
  Date is auto-derived from `build_db.py`'s `CSV_PATH` — never hardcode it.
- Footer bottom-left: "data provided by Open IPF", regular 19px, `--text-dim`.

### 2. Leaderboard slide (`make_leaderboard.py`, `make_p4p.py`)

- Header: inline wordmark + category subtitle + full-width border rule (see
  above).
- Table is **edge-to-edge** (no outer box/border, no side margins on the row
  shading) — rows alternate `--panel` / `--panel-2` from canvas edge to edge.
  This was a deliberate choice: an earlier boxed-card version felt cramped.
- Column header row: semibold 17px `--text-dim`, uppercase, right-aligned
  per numeric column, full-width `--border` rule beneath it.
- Rank badge: 20px-radius circle, bold 20px number. Gold/silver/bronze fill
  with dark (`#1a1a1a`) text for ranks 1–3; `--panel-2` fill with `--text-dim`
  number for everyone else.
- Row height is computed to fill all available vertical space down to the
  footer — never fixed — so 15 rows always use the canvas fully regardless of
  header size.
- **One metric per slide is the headline**: bold, larger, `--accent`. Every
  other numeric column is regular/semibold `--text` or `--text-dim`. Never
  make two columns compete for attention.
  - Weight-class leaderboards: **Total** is the headline metric.
  - Pound-for-pound leaderboards: **Dots** is the headline metric; Total is
    demoted to a secondary (semibold, plain `--text`) column.
- Column order:
  - Weight-class: `# · LIFTER · BW · DATE · TOTAL · DOTS`
  - Pound-for-pound: `# · LIFTER · CLASS · BW · DATE · TOTAL · DOTS`
- Lifter names: OpenIPF duplicate-name suffixes (`" #2"`, `" #13"`, …) are
  stripped for display. Long names shrink via `fit_size()` (25px down to a
  16px floor) rather than wrapping or truncating.
- Footer bottom-left: "data provided by Open IPF" (same as title slide).

### 3. Outro / CTA slide (`make_title_slide.py` → `build_cta_slide`)

Closes every carousel. Same wordmark treatment as the title slide, no footer.

- "IF YOU LIKE CONTENT LIKE THIS" — bold, 54px, `--text`, centered at 50%
  height.
- "FOLLOW ALONG FOR MORE" — semibold, 34px, `--accent`, directly below.
- Handle "@ipf_ranked" — bold, 46px, `--text`, centered at 63% height.

## File naming (so a carousel sorts correctly in a file browser)

- `0_title_*.png` — title slides sort first.
- `{SEX}_{CLASS}_top15.png` (e.g. `M_83_top15.png`, `F_84plus_top15.png`) —
  weight-class leaderboards. `+` becomes `plus` (filesystem-safe).
- `p4p_{sex}_top15.png` — pound-for-pound leaderboards.
- `z_outro_follow.png` — CTA slide sorts last.

## Regenerating the graphics

```
.venv\Scripts\activate
python scripts/social/make_title_slide.py --out-dir "C:\Users\fabio\Desktop\ipfranked_graphics"
python scripts/social/make_leaderboard.py --out-dir "C:\Users\fabio\Desktop\ipfranked_graphics"
python scripts/social/make_p4p.py --out-dir "C:\Users\fabio\Desktop\ipfranked_graphics"
```

`--out-dir` defaults to `social/output/` (gitignored) if omitted. All three
scripts read from `data/openipf.duckdb` — rebuild that first (see main
README) if the data snapshot changed.

## Ranking rules referenced by these graphics

These aren't a visual-design concern, but they determine what the graphics
*say*, so keep captions consistent with them:

- Raw (unequipped), full power (SBD) meets only.
- Each lifter's **best** Total (or best Dots, for pound-for-pound) in the
  **last 2 years** — not whichever meet is most recent, so a worse follow-up
  meet can't bump someone down.
- Ties on Total within a weight class break on lower bodyweight, then
  earlier meet date.
- A meet with no recorded weight class has one inferred from bodyweight
  against the standard IPF thresholds (see `inferred_class_sql` in
  `scripts/build_db.py`), so results like Sheffield Powerlifting
  Championships aren't silently dropped.

## Extending this guide

Adding a new slide type or metric? Add it to `shared.py` as a reusable
helper if it'll be used more than once, document it here under "Slide
types," and keep the "one headline metric per slide" rule — it's the single
biggest thing keeping these graphics legible.
